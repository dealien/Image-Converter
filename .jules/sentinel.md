## 2026-05-01 - Fix path traversal in metadata file handling\n**Vulnerability:** User-provided paths in metadata file arguments allowed path traversal (Arbitrary File Read) to read sensitive system files.\n**Learning:** In local CLI scripts, naive file path usages `open(path)` could lead to arbitrary file reads when paths are not correctly bound to the expected directory.\n**Prevention:** Apply `os.path.basename` to user-provided paths when they are strictly expected to only be local filenames, such as for metadata importing or exporting from the working directory.
